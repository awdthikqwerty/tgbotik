# Current reference review

This is a visual read of the material currently in the reference folders. The inventory has 16 individual JPG frames in `references/frames/` and 5 contact sheets in `references/sheets/`. Re-run `npm run references` after adding or replacing material; this is a qualitative note, while the generated JSON is the live inventory.

## Visual families in this batch

1. **Colorful cartoon characters in stylized 3D worlds** — repeated bean/head-shaped flat characters with dark ink outlines, expressive faces and simple limbs; painterly or textured rooms, streets, game-show/cowboy/classroom sets; saturated color, clear foreground/background depth, close-ups and group tableaux. This aligns most closely with the studio's default Cartoon 3D pipeline and should be the starting look when the script gives no stronger direction.
2. **Dark illustrated explainer / safety-story scenes** — vertical framing, restrained blue/green/brown palettes, high-contrast short labels or interface-like panels, doors/windows/hallways, and strong shadow. Treat as a separate optional direction for tense or instructional scenes; do not carry its UI overlays into unrelated stories.
3. **Red/pink surreal portal sequence** — one contact sheet is dominated by luminous red doors, repeated frames and soft glow/blur. Treat this as a specific mood/transition reference, not the default palette or a motif to repeat automatically.
4. **Vintage title-card and numeric/UI inserts** — some individual frames contain sepia typography, message screens, game-show labels, or number grids. Recreate the narrative function with original text/graphics only when useful; don't copy their wording or layout literally.

## Direction for using this set

The collection is mixed, so don't average all colors and motifs into one look. First read the user's story and request, then choose the closest family or combine only compatible traits. Preserve the story's premise, characters, intended meaning and ending. Borrow broad visual principles such as outlined 2D figures against detailed 3D sets, layered depth, purposeful gliding camera and selective dramatic lighting. Keep any on-screen text original and in the selected language. Use full-size frames for detail decisions; contact sheets are for overview and pacing.
