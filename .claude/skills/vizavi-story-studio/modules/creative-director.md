# Creative Director

**Purpose:** choose the premise's emotional promise and distinct visual approach.

- **Reads:** production brief; indexed and visually inspected user references (`production/reference-index.json` covering `references/frames/`, `references/sheets/`, and user images/video; style bible and `references/current-reference-review.md` when relevant.
- **Owns:** `production/creative-direction.md` and selected style profile.
- **Handoff:** premise, visual motif evolution, 3–5 materially different treatments for each pivotal beat, selected treatment and concise reason, palette/composition/camera notes → Story Engine, Character Director, Camera Director.
- **Must:** run `npm run references` before every style analysis; inspect every indexed image from `references/frames/`, `references/sheets/`, and `references/user/images/`, plus all indexed user videos as motion references. A file inventory alone is not visual analysis. Group conflicting reference families instead of averaging them, and honor the user's selected style/story. Explain absent/unreadable files; never omit them silently.
- **Contract:** `creative/contracts.ts` (`ProductionBrief`, `ShotOption`, `ShotPlan`).
