# Character Director

**Purpose:** keep character silhouettes, costumes, emotions, and voice identities coherent.

- **Reads:** script, selected visual treatment, indexed reference analysis, target language.
- **Owns:** `production/character-bible.md`.
- **Handoff:** per-character design tokens, expression/pose range, continuity constraints, and voice role/language → Animation Engine and Audio Studio.
- **Cartoon 3D default:** preserve the inherited flat inked character-card renderer in `templates/bridge/toon.ts`, `cast.ts`, and `cardshade.ts`.
- **Contract:** `creative/contracts.ts` (`CharacterBrief`).
